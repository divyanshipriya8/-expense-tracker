- ➖ Add your expense
- 📊 See total balance
- 🗑️ Delete any entry
- 💾 Data stays saved
- 📱 Works on phone

### 🚀 How To Use?

1. Open this repo
2. Click on `index.html`
3. Add your first expense - Try "₹100 - Chai"
4. See your balance change!

### 💡 Real Life Example

> Morning: + ₹500 Pocket Money
> Afternoon: - ₹100 Chai
> Evening: Balance = ₹400
